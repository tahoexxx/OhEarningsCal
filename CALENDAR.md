# Market calendars

The original `customstock.ics` URL, parser fields, watchlist Variables and earnings
generator are unchanged. Two independent subscriptions are generated by the same
Pages workflow: `ics/macro.ics` and `ics/company-events.ics`. The public
`ics/market-calendar.json` manifest supplies detailed source health to dashboards.

Run `pnpm run fetch` (not pnpm's built-in `fetch` command), `pnpm run gen`,
`pnpm run calendar`, and `pnpm test`. Node 24 is used in Actions. No new dependency,
API secret, paid model, external notification, or change to cron cadence is needed.
GitHub schedules can be delayed: this is a planning calendar, not a release-time
delivery service. Dashboard countdowns run locally against stored timestamps.

## Sources and correctness

- Nasdaq economic calendar: headline/core CPI, PPI, nonfarm payrolls and
  unemployment are grouped by release. No actual/consensus numbers are published.
  Its queried date and `gmt` field are NOT trusted as date/UTC. Every build solves
  the date offset and timezone against at least two official events, including
  Fed monthly calendar timestamps and an audited 2026 BLS schedule snapshot.
  Conflicting or insufficient evidence withholds the new Nasdaq batch and keeps
  its last good data. BLS anchors in `src/calendar/nasdaq.js` are calibration
  evidence, not a live feed. Review and renew them when the official schedule
  changes or at year rollover. Fixed weekdays alone are not proof.
- Federal Reserve annual calendar supplies meeting ranges and SEP flags. Monthly
  calendars supply precise decision, conference and minutes timestamps. An annual
  date without a monthly time remains date-only. No +21-day guess for minutes.
- BEA release schedule supplies GDP estimate types and PCE release instants.
- Apple Developer RSS: exact special-event invitation language is extracted and
  converted using America/Los_Angeles. Publication date is not event date.
  Other potentially relevant announcements go to a review queue rather than
  becoming invented confirmed events.

IANA timezones handle US DST. ICS times are UTC, date-only events remain date-only.
Each new event has a stable UID, and known changes increment its sequence.
Nasdaq's identity is release type + scheduled month: unusual double releases in a
month fail validation and need review. Disappearance from a rolling source is NOT
treated as cancellation. Date-only Fed meeting ranges use an exclusive end date.

## Source health and failure behavior

`generated_at` and ICS DTSTAMP mean build time. `sources.*.last_success` and event
`last_verified` mean successful collection/verification, and are retained during
errors. Regenerating an old cache must never reset those fields. A source page that
has not changed is normal; successful revalidation is sufficient. An invalid or
empty parser result keeps its previous valid events. Nasdaq empty days are allowed,
but an entirely empty selected batch is rejected. Coverage limits are explicit.

The existing earnings alert checks only `customstock.ics`: adding new files does
not automatically monitor them. The dashboard shows source-specific errors and
staleness. Additional outbound alerts are intentionally not installed here.

`data/market-calendar` is cached separately from earnings. Last published market
files are restored before collection. A timed-out or failed new collector does not
block publication of the original earnings files; existing market files then
retain their previous build and verification times. No secret/private context is
written to the public manifest or cache.

## LLM-assisted review

There is no unattended LLM job or model credential in this repository. A reviewer
(human or Codex/Claude) reads `candidates` and its original official announcement.
Only evidence-backed corrections go into `src/calendar/reviewed-events.json`.
Use the same stable event ID when correcting an event; include its exact source,
evidence, last_verified, reviewer and content_hash. For non-events or duplicate
announcements add a dismissal with candidate ID + content hash. Changed source
text invalidates the dismissal and brings the item back for review. Never put
private holdings, company strategy, tokens or local handoff documents here.

Current automatic company coverage is Apple special events. WWDC/keynote pages
without the supported exact invitation format require review. Additional companies
need explicit official sources and fixtures before enabling automatic publication.

## Release and rollback

Before deploying, compare all pre-existing ICS files from the old and new generator
using the SAME earnings cache and Variables, ignoring only DTSTAMP and UID. Run
fixture tests, two live collections, and check UTC/date conversions in a real
browser. New public files must return 200 after the Pages deployment. A revert
commit can remove the new calendar step while leaving earnings unchanged.
Consumers should keep the last valid manifest if Pages is unavailable.

Fixtures under `src/calendar/fixtures` are minimized official/Nasdaq responses
captured 2026-09-11. The BLS schedule calibration sources are linked in the code.
